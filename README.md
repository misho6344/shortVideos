# shortVideos

ფილმიდან YouTube Shorts-ის ფორმატის (9:16, მაქსიმუმ 3 წუთი) ტრეილერის ავტომატური გენერაცია.

პროგრამა იღებს არქივში (`.zip`, `.tar.*`, `.rar`, `.7z`) ჩაწყობილ ფილმს, პოულობს მასში ყველაზე საინტერესო მომენტებს
(ხმის სიმძლავრე, სცენის გადასვლები, დიალოგის სიმჭიდროვე) და აწყობს მათგან ერთ ვერტიკალურ ვიდეოს.

## მოთხოვნები

- Python 3.9+
- `ffmpeg` და `ffprobe` (PATH-ში)
- სურვილისამებრ: `7z` ან `unrar` ან `bsdtar` — მხოლოდ `.rar` / `.7z` არქივებისთვის

დამატებითი Python პაკეტები არ სჭირდება.

## გამოყენება

```bash
python3 make_trailer.py movie.zip -o out/trailer.mp4
```

სათაურით და ქართული შრიფტით:

```bash
python3 make_trailer.py movie.zip -o out/trailer.mp4 \
    --title "ფილმის სახელი" \
    --font /usr/share/fonts/truetype/freefont/FreeSans.ttf
```

ქართულენოვანი შრიფტის პოვნა:

```bash
fc-list :lang=ka file
```

## რას აკეთებს პროგრამა

1. ხსნის არქივს და პოულობს ყველაზე დიდ ვიდეო ფაილს. თუ არქივში არის `.srt` სუბტიტრი იმავე სახელით (ან ერთადერთი `.srt`), იყენებს მას.
2. აანალიზებს ფილმს: ხმის სიმძლავრეს ყოველ წამზე, სცენის გადასვლებს (ffmpeg-ის `scene` ფილტრით) და დიალოგს (სუბტიტრებიდან).
3. თითოეულ წამს ანიჭებს ქულას და პოულობს ყველაზე ძლიერ, ერთმანეთს არ გადაფარავ მომენტებს. ფილმის დასაწყისსა და ბოლო ტიტრებს თავს არიდებს.
4. ყოველი მომენტის საზღვრებს აფართოებს კონტექსტის შესანარჩუნებლად: იწყება სცენის გადასვლაზე ან სუბტიტრის დასაწყისზე და მთავრდება სცენის ბოლოს ან სუბტიტრის დამთავრებისას.
5. ყოველ მომენტს არენდერებს 1080×1920 ფორმატში: ზემოთ და ქვემოთ ბლიურული ფონი, ზედ თავად კადრი, მსუბუქი ფერთა კორექცია, fade-in/out, ხმის ნორმალიზება (-14 LUFS) და ჩაწერილი სუბტიტრები.
6. საბოლოოდ აერთებს ყველაფერს ერთ MP4 ფაილად და წერს `.json` ფაილს არჩეული მომენტებით.

## პარამეტრები

| პარამეტრი | ნაგულისხმევი | აღწერა |
|---|---|---|
| `-o, --output` | `trailer.mp4` | გამოსავალი ფაილი |
| `--duration` | `170` | სასურველი სიგრძე წამებში (მაქსიმუმ 180) |
| `--clip-length` | `12` | თითო მომენტის სასურველი სიგრძე |
| `--min-clip` / `--max-clip` | `4` / `20` | მომენტის მინიმალური / მაქსიმალური სიგრძე |
| `--gap` | `8` | მინიმალური მანძილი ორ არჩეულ მომენტს შორის |
| `--scene-threshold` | `0.35` | სცენის გადასვლის მგრძნობელობა (დაბალი = მეტი ჭრა) |
| `--subs` | ავტომატური | კონკრეტული `.srt` ფაილი |
| `--no-subs` | — | სუბტიტრების დაწვა არ მოხდეს |
| `--font-name` | `Noto Sans Georgian` | სუბტიტრების შრიფტის სახელი (უნდა უჭერდეს ქართულს) |
| `--sub-size` | `20` | სუბტიტრის ზომა |
| `--sub-margin` | `180` | სუბტიტრის დაშორება ქვედა კიდიდან |
| `--title` | — | სათაური დასაწყისში (საჭიროა `--font`) |
| `--font` | — | TTF შრიფტი სათაურისთვის |
| `--order` | `chronological` | მომენტების თანმიმდევრობა: `chronological` (ფილმის მიხედვით) ან `score` (ქულის მიხედვით) |
| `--work-dir` | — | შუალედური ფაილების შესანახი საქაღალდე (ნაგულისხმევად იშლება) |

## შენიშვნები

- **დრო.** სცენის გადასვლების ძიება ფილმის სრულ დეკოდირებას მოითხოვს. 2-საათიანი ფილმი რამდენიმე წუთს შეიძლება მოითხოვდეს.
- **ავტორის უფლებები.** გამოიყენე მხოლოდ იმ მასალა, რომლის გამოყენების უფლებაც გაქვს.
- **სუბტიტრების ზომა.** ძალიან დიდი `--sub-size` ან `--sub-margin` შეიძლება ტექსტს ეკრანიდან გამოათიშოს. ნაგულისხმევი მნიშვნელობები ტესტირებულია.
- **YouTube Shorts.** პროგრამა არ აჭარბებს 180 წამს. თუ ფილმის ტრეილერი ჯერ კიდევ მოკლეა, მომენტები ყველა შესაძლებელ ადგილას აიღება.
